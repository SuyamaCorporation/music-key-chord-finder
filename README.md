# Music Key & Chord Progression Finder

## 概要
キー（C〜B, major/minor/dorian/mixolydian）を選ぶとダイアトニックコード7種を一覧表示し、各コードをクリックするとギターコードダイアグラムと典型的な進行例を表示する。

## 機能
- 12ルートノート × 4モード（major/minor/dorian/mixolydian）
- ダイアトニックコード7種の表示（ローマ数字付き）
- コードクリックでギターコードダイアグラム（SVG）表示
- 典型的なコード進行例の表示

## 使い方
ルートノートとモードをドロップダウンで選択すると、そのキーのダイアトニックコードが表示されます。コードボタンをクリックするとギターコードダイアグラムと使用例が表示されます。
